### A-4. 엔진 `js/engine/`
UI(B)가 쓰는 함수는 아래 셋뿐입니다. 이 형태는 B와의 약속이므로 바꿀 때는 먼저 알립니다.

| 함수 | 하는 일 | 돌려주는 값 |
|---|---|---|
| `TarotEngine.load()` | `data/*.json` 불러오기(시작할 때 한 번) | 완료 신호 |
| `TarotEngine.createDeck()` | 78장을 무작위로 섞고 카드마다 정/역방향을 50%로 정함 | `[{ cardId, orientation }]` 78개 |
| `TarotEngine.buildPrompt(request)` | 프롬프트 조립 | `{ text, length }` |

보조로 `TarotEngine.getSpreads()`(메뉴 목록: 이름·장수·설명·자리·배치 종류), `TarotEngine.getCard(cardId)`(이름·이미지 경로) 제공 — 홈 메뉴와 카드·자리 이름을 표시할 때 사용.

- [ ] `load()`, `getSpreads()`, `getCard()`
- [ ] `createDeck()` — 역방향 확률은 설정값 `REVERSED_RATE = 0.5`
- [ ] `buildPrompt()` — 아래 순서
  1. 입력 글 정리: 앞뒤 공백 제거, 줄바꿈을 공백으로, 2,000자 초과분 자르기(`MAX_INPUT_LENGTH = 2000`)
  2. 카드 이름 조회, 역방향이면 ` (역방향)` 붙이기
  3. 스프레드 설정에 따라 선택 항목을 넣거나 빼고, 생각 순서 번호 다시 매기기
  4. 틀에 채워 한 덩어리 글로 만들기
- [ ] 잘못된 요청 처리: 없는 카드 ID, 카드 수 불일치 → 알아볼 수 있는 오류 메시지
- [ ] 쿠키·저장소·외부 요청을 쓰지 않음(코드에 `localStorage`, `document.cookie` 없음)
- [ ] 기존 `js/app.js` 의 해석 생성 코드(`interpretCard`, `summarize`) 삭제는 B와 시점 조율

**완료 기준**: 브라우저 콘솔에서 `buildPrompt()` 를 호출하면 4.3과 같은 형식의 글이 나옴
