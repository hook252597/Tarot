## 화면별 참고 이미지 및 한 줄 평가

### 1. 전체 분위기 — S1. 홈 화면 (`assets/ui/s1-home.png`)
* **참고 이미지**: `assets/ui/s1-home.png`
* **어디가 좋은지**: 깊이감 있는 딥 네이비·퍼플 밤하늘 배경과 반투명 글래스모피즘 카드가 어우러져 '달빛 아르카나' 특유의 신비롭고 몰입감 높은 무드를 연출하며, 대표 메뉴인 '오늘의 운세'와 각 스프레드의 장수가 한눈에 직관적으로 구분됨.

### 2. 상황 입력 — S2. 상황 입력 화면 (`assets/ui/s2-input.png`)
* **참고 이미지**: `assets/ui/s2-input.png`
* **어디가 좋은지**: 선택한 메뉴와 자리 미리보기가 상단에 깔끔하게 배치되고, "누구와, 어떤 일로, 무엇이 궁금한지" 구체적인 입력을 유도하는 가이드 문구와 글자 수 표시(0/2,000자)가 명확해 사용자 편의성이 우수함.

### 3. 카드 고르는 화면 — S3. 카드 선택 화면 (`assets/ui/s3-select.png`)
* **참고 이미지**: `assets/ui/s3-select.png`
* **어디가 좋은지**: 상단에 뽑은 카드가 채워질 자리 슬롯(1. 상황 / 2. 과제 / 3. 결과)과 진행 상태("1 / 3 선택")가 실시간으로 보이고, 78장 덱이 아름다운 궤적으로 넓게 펼쳐져 타로를 직접 뽑는 연출과 손맛이 잘 살아있음.

### 4. 결과 화면 — S4. 결과 화면 (`assets/ui/s4-result.png`)
* **참고 이미지**: `assets/ui/s4-result.png`
* **어디가 좋은지**: 정방향·역방향 카드가 시각적으로 명확히 구분되며, 가장 중요한 기능인 '프롬프트 복사' CTA 버튼과 외부 AI 서비스(ChatGPT, Gemini) 바로가기 링크가 중앙에 시선집중되어 사용자의 다음 동작 유도가 매우 명쾌함.
