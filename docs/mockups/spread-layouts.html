스프레드별 화면 설계안 — 오늘의 운세 · 관계 스프레드 · 켈틱 크로스

동업자가 올린 참고 이미지(assets/ui/s1~s4)의 색·패널·버튼·카드 표현을 그대로 따르고, 오늘의 운세(3장)는 참고 이미지대로, 참고 이미지에 없는 7장·10장 스프레드는 같은 패턴으로 S2(입력)·S3(카드 선택)·S4(결과) 화면을 설계한 안입니다. 왼쪽은 PC, 오른쪽은 모바일(360px)입니다. 카드 뒷면과 배경은 CSS로 흉내 낸 것이며 실제 이미지는 B의 디자인으로 교체합니다.

1. 오늘의 운세 (3장)

참고 이미지(s3-select.png, s4-result.png)의 구성을 그대로 옮긴 기준 화면입니다. 한 줄 배치: ① 상황 · ② 과제 · ③ 결과. 순서대로 놓이므로 번호 배지·카드 목록 없이 카드 위에 자리 이름, 아래에 카드 이름과 방향을 적습니다. 원 카드·쓰리 카드도 같은 배치를 씁니다.

2. 관계 스프레드 (7장)

배치: 위 ③ / ①·② / ④·⑥·⑤ / 아래 ⑦. 왼쪽 줄은 나(①④), 오른쪽 줄은 상대(②⑤), 가운데 점선은 관계의 흐름(③→⑥→⑦).

3. 켈틱 크로스 (10장)

배치: 십자 6장 + 오른쪽 세로 4장. ②는 ① 위에 가로로 눕힘. 점선은 가로 흐름(③→①→④)과 세로 흐름(⑥→①→⑤). 모바일에서는 세로 4장(⑦~⑩)을 십자 아래 한 줄로 내립니다.
