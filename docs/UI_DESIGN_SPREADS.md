# 관계 스프레드 · 켈틱 크로스 화면 설계

| 항목 | 내용 |
|---|---|
| 작성 | A (B의 참고 이미지를 바탕으로 한 제안) |
| 기준 | `assets/ui/s1-home.png` ~ `s4-result.png`, `docs/R-01_UI_NOTES.md`, `docs/DEVELOPMENT.md` v0.13 |
| 화면 시안 | **`docs/mockups/spread-layouts.html`** — 브라우저로 열면 PC·모바일(360px) 화면 12개가 보임 |
| 상태 | 제안 — 화면 설계의 최종 결정은 B |

참고 이미지에는 1장·3장 스프레드 화면만 있어, 7장(관계 스프레드)과 10장(켈틱 크로스)의 S2·S3·S4 화면을 같은 색·패턴으로 설계했다. 시안 파일의 CSS는 구현 때 그대로 가져다 쓸 수 있게 작성했다.

## 1. 참고 이미지에서 가져온 디자인 패턴

| 요소 | 참고 이미지의 표현 | 이 설계에서의 사용 |
|---|---|---|
| 배경 | 짙은 남색 밤하늘 + 보라·주황 성운 + 별 | 동일(시안은 CSS로 흉내, 실제는 B의 배경 이미지) |
| 패널 | 반투명 어두운 판 + 금색 얇은 테두리 + 은은한 금빛 번짐, 둥근 모서리 | 동일. 7장·10장은 내용이 많아 패널 최대 폭을 넓힘(약 760 → 980px) |
| 제목 | 금색 큰 글자, 가운데 정렬 | 동일 |
| 진행 표시 | 제목 아래 "1 / 3 선택" | 동일("3 / 7 선택", "4 / 10 선택") |
| 자리 칸 | 반투명 유리 카드 + 안쪽 테두리, 아래에 "1. 상황" | 동일. 번호는 카드 왼쪽 위 금색 동그라미로 옮김(배치가 복잡해 번호가 먼저 보여야 함) |
| 카드 뒷면 | 보라 바탕 + 금색 달 무늬·테두리 | 동일(시안은 CSS 근사) |
| 주 버튼 | 금색 그라데이션 알약 모양 + 빛 번짐 | 동일(카드 펼치기, 결과 보기, 프롬프트 복사) |
| 보조 버튼 | 금색 이중 테두리 알약 모양 | 동일(다른 방식 고르기, 다시 섞기, 다시 뽑기, 다른 메뉴 보기) |
| 복사 영역 | "1. 복사 → 2. AI 열기 → 3. 붙여넣기" 종이 모양 + 복사 버튼 + ChatGPT \| Gemini 링크 | 동일 |
| 머리말·바닥글 | 달 아이콘 + 사이트 이름, "처음으로", 면책 문구 | 동일 |

## 2. 7장·10장에서 새로 추가한 것

카드 수가 많아지면 참고 이미지의 구성만으로는 부족한 부분이 있어 다음을 추가했다.

| 추가 요소 | 이유 | 화면 |
|---|---|---|
| **번호 배지** — 카드·자리 칸 왼쪽 위 금색 동그라미 | 배치가 번호 순서대로 놓이지 않음(관계: ③이 맨 위). 번호가 자리 이름보다 먼저 보여야 함 | S2·S3·S4 |
| **다음 자리 강조** — 다음에 채워질 칸에 금색 점선 테두리 + 빛 | 7장·10장은 "지금 고르는 카드가 어느 자리로 가는지"를 놓치기 쉬움. 칸 아래에 "빛나는 칸이 다음에 채워질 자리입니다 — 4. 내가 원하는 것" 문구 | S3 |
| **흐름 안내선** — 함께 읽는 카드를 잇는 옅은 금색 점선 | 두 스프레드 모두 카드 묶음으로 읽는 것이 핵심(프롬프트의 해석 지침과 같은 묶음) | S3·S4 |
| **카드 목록** — 번호 · 자리 · 카드 이름 · 방향을 줄 단위로 | 배치 위에서는 카드가 작아 이름·방향을 다 적을 수 없음. PC는 배치 오른쪽, 모바일은 배치 아래 | S4 |
| **묶음 설명** — "③ → ⑥ → ⑦ 관계·과제·흐름" 같은 한 줄씩 | 안내선이 무엇을 뜻하는지 알려줌 | S4 |
| **자리 이름 칩** — "1 나", "2 상대" … | 입력 화면의 작은 미리보기에는 이름을 넣을 자리가 없음 | S2 |
| **역방향 표시** — 그림 180° 회전 + 오른쪽 아래 "역" 표시 + 목록에 "역방향" | 카드가 작아 뒤집힌 것을 못 알아볼 수 있음 | S4 |

## 3. 관계 스프레드 (7장)

### 배치
```
        [3]
     [1]   [2]
   [4] [6] [5]
        [7]
```
- 6칸 격자에 카드 한 장이 2칸씩 차지. ①·②는 ④·⑤와 같은 열에 두되 10px씩 안쪽으로
- 가운데 세로 점선: ③ → ⑥ → ⑦ (관계·과제·흐름)
- 왼쪽 = 나(①④), 오른쪽 = 상대(②⑤)

| | PC | 모바일(360px) |
|---|---|---|
| 카드 폭 | 74px | 66px |
| 배치 폭 | 약 280px | 약 250px — 화면에 그대로 들어감 |
| S4 구성 | 왼쪽 배치 + 오른쪽 카드 목록 | 배치 → 묶음 설명 → 카드 목록 → 복사 영역 |

### 입력 화면 예시 문구
"예) 사귄 지 1년 된 사람과 요즘 연락이 줄었습니다. 서로 바라는 게 달라진 건지, 무엇을 풀어야 할지 궁금해요."

## 4. 켈틱 크로스 (10장)

### 배치
```
PC                          모바일
      [5]        [10]             [5]
 [3] [1/2] [4]   [9]         [3] [1/2] [4]
      [6]        [8]              [6]
                 [7]         [7] [8] [9] [10]
```
- 십자 6장: 가운데 ① 위에 ②를 90° 눕혀 겹침. 가로 점선 ③–①–④, 세로 점선 ⑥–①–⑤
- 오른쪽 세로 4장: 아래 ⑦부터 위 ⑩까지. 자리 이름은 카드 오른쪽에
- **모바일**: 세로 4장을 십자 아래 한 줄(⑦ ⑧ ⑨ ⑩)로 내림. 가로 흐름 ③–①–④는 한 줄로 유지
- ①·② 자리 이름은 겹친 카드 아래에 "현재 상황 · 장애물"로 함께 표시
- 눕힌 ②의 번호 배지와 "역" 표시는 글자가 바로 서도록 반대로 돌림

| | PC | 모바일(360px) |
|---|---|---|
| 카드 폭 | 66px | 60px |
| 배치 폭 | 십자 약 290px + 세로줄 약 170px | 십자 약 250px, 아랫줄 4장 약 270px |
| S4 구성 | 왼쪽 배치 + 오른쪽 카드 목록(10줄) | 배치 → 묶음 설명 → 카드 목록 → 복사 영역 |

### 입력 화면 예시 문구
"예) 3년 다닌 회사를 그만두고 디자인 일을 새로 시작하려 합니다. 준비는 6개월 했고, 지금 옮겨도 될지와 무엇이 걸림돌인지 궁금해요."

## 7. 데이터와의 연결 (A 작업)

화면이 배치를 그릴 수 있도록 `data/spreads.json` 에 다음을 둔다.

| 필드 | 값 | 용도 |
|---|---|---|
| `layout` | `row`(1장·3장) / `relationship7` / `celtic10` | 배치 종류 — 화면은 이 값에 맞는 CSS 배치를 적용 |
| `groups` | 예: `[{ "label": "③ → ⑥ → ⑦", "desc": "관계·과제·흐름" }]` | S4의 묶음 설명. 프롬프트의 해석 지침과 같은 내용 |
| `inputExample` | 스프레드별 예시 문구 | S2 입력 칸 안내 |

새 스프레드를 추가할 때 배치가 기존 종류에 없으면 `layout` 종류와 CSS를 하나 추가한다.
